# Release evidence gallery

## Purpose

This gallery lets readers inspect six unchanged captures of the released TrafficMonitor 1.0.48
interface. Use the category selector to focus on setup, settings, or regular-expression examples.
Select an image to open a larger view; close it with the close button or Escape. The selector and
image controls work by keyboard as well as pointer.

## Included states

The gallery contains setup language and startup, interface and notification settings, a local
regular-expression test, and a literal replacement preview. Each image is labelled as released
before-state evidence. Their capture times, dimensions, SHA-256 digests, and exact source links
are listed in the public inventory.

## Review and scope

The six files were reviewed and copied byte-for-byte from the released build evidence. The source
revision is `ddcf441f4c3cab2a5e3b62e9ff6aff1babf3bdfa`; the release is 1.0.48. No excluded image
was edited or redacted. One workspace image was excluded because it contained host or network
identity and incomplete chart rendering. Private process, machine-path, and restoration records
are not published.

These captures show English, light appearance, and actual 96 DPI only. They do not establish
keyboard and UI automation, bilingual or dark-appearance coverage, display-scale acceptance, or
completion of the ongoing visual refinement. Read the source release and revision links for
project context.

## Maintenance

Update the inventory and images together only after reviewing each original, its provenance,
privacy, scope, dimensions, timestamp, and digest. Preserve exact original bytes. Do not present
these images as evidence for a newer build or completed acceptance without new verified evidence.
